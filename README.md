Hi, I’m Hemant Garg, a Backend Engineer with 2+ years of experience building production-grade services using Java and Spring Boot. I enjoy the parts of backend work that decide whether a system is merely working or actually reliable: clean API design🔌, secure access control🔐, efficient database access, solid testing 🧪, and smooth deployments.

I like understanding *why* something is slow, *why* it broke, and *how* to make sure it doesn't break again. I'm also an active problem solver on competitive programming platforms, which keeps my fundamentals sharp.

---

### 💡 What I Bring to the Team

- **Problem Solving:** Strong DSA foundation, regular practice on LeetCode, Codeforces, and CodeChef
- **Debugging & Performance Tuning:** Comfortable reading logs, SQL query plans, and profiling slow code paths to find real root causes
- **Security Mindset:** I treat authentication, authorization, and data isolation as core design concerns, not add-ons
- **Quality Ownership:** I write code that is testable, and I back it with unit and integration tests
- **End-to-End Delivery:** I'm comfortable taking a feature from API design to database to CI/CD to deployment
- **Fast Learner:** I pick up new tools and domains quickly and use AI tools wisely to speed up work while still reviewing and understanding every line
- **Clear Communication:** Good at documenting APIs, explaining trade-offs, and collaborating with teammates
